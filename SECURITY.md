# Security Policy

## Supported Versions

Currently, only the latest version of `kill-my-port` is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `kill-my-port`, please do **not** open a public issue or discussion. 

Instead, please report it privately:
- Go to the **Security** tab of this repository.
- Click on **Advisories** in the sidebar.
- Click **Report a vulnerability**.
- Provide a detailed summary of the vulnerability, including steps to reproduce.

We take security seriously and will respond to reports as quickly as possible. Once the vulnerability has been resolved, we will publish a security advisory and notify the community.
